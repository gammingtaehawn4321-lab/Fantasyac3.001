Fantasyac CC0 equipment icons

Source pack: 496 pixel art icons for medieval/fantasy RPG
Artist: Henrique Lazarini (7Soul1)
License: CC0 / Public Domain
Source archive: 496_RPG_icons.zip

The /source directory preserves the original 496 34x34 RGBA PNG icons.
The /mapped directory contains deterministic pixel-art composites made only from those CC0 icons for Fantasyac equipment display.
No AI-generated image assets are used in this equipment-art patch.
