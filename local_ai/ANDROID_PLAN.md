# Android Local Narrator 계획

대상 기준 기기: Galaxy A17 한국판 SM-A175N, RAM 6GB.

## 원칙

- Termux 같은 외부 터미널 앱을 요구하지 않는다.
- 판타지악 Android 앱 내부에 네이티브 로컬 LLM 런타임을 포함한다.
- 게임 코드가 보는 Narrator 인터페이스는 PC와 동일하다.
- 기본 안전 프로필은 Qwen3 1.7B Q4_K_M, 컨텍스트 3072.
- 기기 실측 후 4B 프로필은 선택형으로 추가할 수 있다.

## 동일 기능

세이브/퀘스트/전투/펫/사용자 참조/로그 요청 계약은 PC와 동일하다. Android만 모델 크기와 컨텍스트가 다르다.
